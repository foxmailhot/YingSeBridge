# 映色桥 YingSeBridge

剪映 ↔ DaVinci Resolve 素材转接工作台，Windows x64 便携版。

**此仓库只分发软件包与版本说明，不上传项目源码、用户草稿或素材。**

## 下载

[下载最新完整便携包](https://github.com/foxmailhot/YingSeBridge/releases/latest/download/YingSeBridge-windows-x64.zip) · [版本说明与历史版本](https://github.com/foxmailhot/YingSeBridge/releases)

完整解压 ZIP 后运行 `YingSeBridge.exe`，必须保留 `_internal` 文件夹，不能只复制 EXE。无需安装 Python。

## 主要功能

- 项目池按最近修改时间排序，读取时间线已用视频。
- 按源规格分组复制原片，创建对应达芬奇导出目录。
- 调色文件匹配、勾选部分素材、校验后回填。
- 一键还原原素材连接并检查实际链接。
- 新建工单、迁移已有调色结果、保留依赖后将旧工单移入回收站。
- 本地画面匹配与可撤销改名。
- 从 2.5 起支持软件右上角“检查更新”，确认后下载校验、更新并重启。

## 运行要求

Windows x64，目前适配剪映 Windows 正式版 **11.6.0.14552 / 11.5.0.14471**。可自动查找剪映，也可在“运行组件”中手动指定安装位置。回填、还原、清理旧工单前请保存并完全退出剪映。

2.5 为更新渠道首版，旧版需先手动完整解压升级一次，以后可在软件中检查新版。请在剪映里播放验收画面和音频。更多操作说明与第三方许可随软件包提供。
